* Loading States
- 1.1 First Load loading state : The loading state that will wake up the server first before displaying the ui. Basically the first loading to appear to ensure that the server is ready.
- 1.2 Page Load, Reload Page, etc. (generic loading) : This loading is when the user reloads the page, when opens a page and it takes some time for tthe client to provide full page.
- 1.3 Server Reload wait : When the user clicks a page then the server is not providing the data yet, show the loadign state of that data first. until the server provides it. this loads before empty state is propvided. if theres no data really by the server. 
Note:  Loading state should handle error state and error handlings etc.
