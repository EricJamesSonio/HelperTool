# Version 15.0.3 — Team Analytics, Profiles & Port Management

**Release Date:** June 10, 2026

## Overview

Version 15 introduces a new collection of collaboration, analytics, and system management tools designed to provide deeper visibility into repository activity while improving developer workflow management.

This release focuses on:

* Port monitoring and process management
* Contributor analytics and activity tracking
* Team leadership rankings
* Developer profile management
* Repository contribution visualization
* Improved team collaboration insights

The goal of Version 15 is to transform Helper Tool from a repository utility into a comprehensive development intelligence platform by providing meaningful insights into both project activity and contributor performance.

---

# New Features

## Port Manager (15.0.0)

Version 15 introduces the new **Port Manager**.

The Port Manager provides visibility into active network ports running on the local system.

Users can now:

* View currently running ports
* Identify associated processes
* Monitor active services
* Detect occupied ports before launching applications
* Manage development environments more efficiently

In addition, users can:

* Terminate processes directly from the interface
* Free occupied ports instantly
* Resolve port conflicts without leaving the application

This simplifies troubleshooting and improves development workflow efficiency by centralizing port management inside the Helper Tool environment.

## Leadership Rankings (15.0.2)

Version 15 introduces **Leadership Rankings**.

Leadership Rankings automatically evaluate repository contributions and display contributor standings.

The ranking system considers repository activity metrics such as:

* Commit volume
* Code contributions
* Repository participation
* Overall engagement

Features include:

* Contributor leaderboard
* Ranked team standings
* Visual indicators for top contributors
* Crown designation for the leading contributor

This feature provides a clear overview of team participation while encouraging engagement and healthy collaboration.

## Developer Profiles (15.0.3)

Version 15 introduces **Developer Profiles**.

Developer Profiles allow contributors to personalize and showcase their repository presence.

Users can manage:

* Profile image
* Display information
* Email links
* LinkedIn profiles
* Facebook profiles
* TikTok profiles
* Additional social links

Profiles also provide repository-specific analytics including:

* Contribution summaries
* Commit statistics
* Activity history
* Repository engagement metrics

Integrated visualizations display:

* Commit activity trends
* Contribution distribution
* Development patterns

This creates a centralized identity system that combines personal information with repository contribution insights.
