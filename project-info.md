# Helper Tool: Features

Helper Tool is a Windows desktop workspace for developers that combines repository navigation, editing, Git workflows, AI tools, databases, APIs, monitoring, and project utilities in one app.

## Core Project and File Tools

| Feature | What it does |
|---|---|
| Project selection | Open a local repository or switch between previously used projects. |
| Repository file tree | Browse folders and files in a clear expandable view. |
| List and tree views | Switch between a flat file list and a hierarchical folder tree. |
| Fast root navigation | Jump directly to folders near the selected repository root. |
| File search | Search and quickly open files and folders in the active project. |
| Shortcut mode | Paste a list of file paths to automatically select the matching files. |
| File and folder filtering | Include or ignore selected extensions and folders. |
| `.docignore` manager | Configure repository files and folders that Helper Tool should exclude. |
| Create, rename, and move | Add files and folders or reorganize items in the project. |
| File and diff viewer | Open text and media files and inspect generated or Git diffs. |
| Code and Structure generation | Generate a code bundle or a folder-structure report from selected items. |
| Normal, Minified, and Prompt output | Choose readable output, compact code, or AI-prompt-ready output. |
| Generated output viewer | Review and copy generated content before or after saving it. |
| Centralized project storage | Save generated structures and code outside the repository. |
| Recent project history | Automatically remember repositories and their associated storage folders. |
| Context menus | Access common actions by right-clicking files, folders, or the repository root. |
| Desktop tray support | Open, minimize, or control Helper Tool from the Windows tray. |
| Keyboard shortcuts | Configure shortcuts for tools and frequent actions. |

| Feature | What it does |
|---|---|
| IDE Mode | Switch to a VS Code-style workspace with an explorer, tabs, and editor. |

| Syntax highlighting | Read supported languages with color-coded code and a minimap. |

| Codebase search | Search text across the whole repository and jump directly to results. |

| Media viewer | Preview images, video, audio, and PDF files inside the app. |
| Git status in the explorer | See modified, added, deleted, renamed, and conflicted files. |
| Changed-line highlights | Distinguish Git changes and unsaved edits directly in the editor. |
| Side-by-side and inline diffs | Review commit changes in the format that is easiest to inspect. |
| Docked terminal | Run commands in the IDE while keeping the repository editor open. |
| Run and debug actions | Run supported files or perform a stricter language-specific check. |
| Import navigation | Ctrl-click import or require paths to open the referenced file. |
| Folder quick actions | Create files or folders directly inside nested explorer folders. |
| IDE language extensions | Add diagnostics, formatting, run support, and hover details for supported languages. |
| Prettier formatting | Format the current file or all open files, including optional format-on-save. |
| WakaTime tracking | Track coding activity and view today's coding summary. |
| Unsaved-change review | Review all unsaved work before closing or switching context. |
